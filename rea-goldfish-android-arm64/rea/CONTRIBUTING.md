# Contributing

Thanks for helping! This is a beginner-friendly project, so keep it simple.

- **Report bugs**: open an issue with your device (`uname -m`, `termux-info`), REA version (`rea --version`), and the exact command + output.
- **Suggest tools**: open an issue describing the engine and how it runs on arm64.
- **Code changes**: fork, edit, and open a pull request. Keep changes small and explain them.
- **Security**: never commit secrets, API keys, keystores, or private targets.
- **Licenses**: do not add proprietary tools (Hopper, IDA, etc.) or their code.
